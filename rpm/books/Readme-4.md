#### 1. Основы: Что такое класс и объект?

* Класс (Class) — это чертеж, шаблон или схема. Он описывает, какими данными (атрибутами) и поведением (методами) будет обладать объект.
* Объект (Экземпляр класса / Instance) — это конкретная вещь, созданная по этому чертежу.
```
# Это КЛАСС (чертеж)
class Car:
    def __init__(self, brand, color):
        self.brand = brand  # Атрибут (данные)
        self.color = color

# Это ОБЪЕКТЫ (конкретные машины, созданные по чертежу)
my_car = Car("Toyota", "red")
your_car = Car("Ford", "blue")
```

#### 2. Функции внутри классов (Методы)

Функция, определенная внутри класса, называется методом. Методы описывают поведение объекта (что он может делать).
Главное отличие метода от обычной функции — наличие первого параметра self (по соглашению).
* self — это ссылка на конкретный объект, который вызывает этот метод.
* Благодаря self метод понимает, с какими именно данными (атрибутами) конкретного объекта он работает.
```
class User:
    def __init__(self, name):
        self.name = name

    # Это МЕТОД. 'self' ссылается на конкретного пользователя.
    def say_hello(self):
        print(f"Привет, меня зовут {self.name}")
```

### 3. Главное отличие: print против return

Это самая частая ошибка новичков. print и return делают совершенно разные вещи.

##### 🗣️ print (Вывод на экран)
* Что делает: Печатает текст в консоль (терминал). Это "побочный эффект" (side effect).
* Что возвращает: Функция с print всегда неявно возвращает None (ничто).
* Суть: Данные "улетают" на экран. Забрать их обратно в код и использовать для вычислений невозможно.

##### 📦 return (Возврат результата)

* Что делает: Завершает работу метода и отдает результат обратно в ту часть кода, которая этот метод вызвала.
* Что возвращает: Любые данные (число, строку, список, другой объект).
* Суть: Данные остаются внутри программы. Их можно сохранить в переменную, передать в другой метод или использовать в математических операциях.

```
class Calculator:
    
    # Метод с PRINT
    def print_sum(self, a, b):
        result = a + b
        print(f"Результат: {result}")
        # Здесь нет return, значит метод вернет None
        
    # Метод с RETURN
    def get_sum(self, a, b):
        result = a + b
        return result
        # Метод отдает число обратно в код


calc = Calculator()

# --- Смотрим, как это работает ---

print("--- Работа с print ---")
# Мы вызываем метод, он печатает на экран
calc.print_sum(5, 3)  # Выведет: Результат: 8

# Пытаемся сохранить результат в переменную
my_var = calc.print_sum(5, 3) 
print(f"Что в переменной? {my_var}") 
# Выведет: Что в переменной? None (потому что print ничего не возвращает!)


print("\n--- Работа с return ---")
# Метод ничего не печатает на экран сам по себе
calc.get_sum(5, 3)  # В консоли будет пусто!

# Но мы можем СОХРАНИТЬ результат
my_var2 = calc.get_sum(5, 3)
print(f"Что в переменной? {my_var2}") 
# Выведет: Что в переменной? 8

# И мы можем ИСПОЛЬЗОВАТЬ результат дальше в коде
final_result = calc.get_sum(10, 20) * 2
print(f"Итог вычислений: {final_result}") 
# Выведет: Итог вычислений: 60
```

#### 4. Как происходит вызов и выполнение (Жизненный цикл)
```
# 1. ОПРЕДЕЛЕНИЕ КЛАССА
# Python просто запоминает этот код, но пока ничего не выполняет.
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
        print(f"[Система]: Счет для {self.owner} создан.")

    def deposit(self, amount):
        self.balance += amount
        return self.balance  # Возвращаем новый баланс

# 2. СОЗДАНИЕ ОБЪЕКТА (ИНИЦИАЛИЗАЦИЯ)
# Python выделяет память, создает объект и АВТОМАТИЧЕСКИ вызывает __init__
my_account = BankAccount("Иван", 1000) 
# В консоли появится: [Система]: Счет для Иван создан.

# 3. ВЫЗОВ МЕТОДА
# Python ищет метод deposit в объекте my_account, 
# передает туда self (сам объект) и amount (500).
new_balance = my_account.deposit(500)

# 4. ОБРАБОТКА RETURN
# Метод отдал число 1500. Оно присвоилось в переменную new_balance.
print(f"Новый баланс: {new_balance}")
```

#### 5. Базовый пример наследования

```
# Родительский класс (предок)
class Worker:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def work(self):
        return f"{self.name} выполняет свои обязанности"

    def get_info(self):
        return f"Работник: {self.name}, зарплата: {self.salary}"


# Дочерний класс (наследник) — автоматически получает всё от Worker
class Manager(Worker):
    # Здесь мы НЕ пишем __init__, он унаследуется от родителя!
    
    # Добавляем НОВЫЙ метод, которого нет у родителя
    def manage_team(self):
        return f"{self.name} руководит командой"


# Создаем объекты
dev = Worker("Анна", 100000)
boss = Manager("Иван", 200000)

# У boss доступны ВСЕ методы родителя + свои собственные
print(dev.work())          # Анна выполняет свои обязанности
print(boss.work())         # Иван выполняет свои обязанности (унаследовано!)
print(boss.manage_team())  # Иван руководит командой (свой метод)
```
##### 6. Переопределение методов (Override)

```
class Worker:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def get_bonus(self):
        return self.salary * 0.1  # Бонус 10%


class Manager(Worker):
    # Переопределяем метод — у менеджеров бонус больше
    def get_bonus(self):
        return self.salary * 0.3  # Бонус 30%


class Intern(Worker):
    # Переопределяем — у стажёров бонусов нет
    def get_bonus(self):
        return 0


anna = Worker("Анна", 100000)
ivan = Manager("Иван", 200000)
petr = Intern("Пётр", 50000)

print(anna.get_bonus())  # 10000.0  (родительская версия)
print(ivan.get_bonus())  # 60000.0  (переопределённая версия)
print(petr.get_bonus())  # 0        (переопределённая версия)
```

#### 7. Расширение поведения через super()

Иногда нам не нужно полностью заменять метод родителя, а лишь дополнить его. Для этого используется функция super(), которая обращается к родительскому классу.

```
class Worker:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def get_info(self):
        return f"Имя: {self.name}, Зарплата: {self.salary}"


class Manager(Worker):
    def __init__(self, name, salary, team_size):
        # Вызываем __init__ родителя, чтобы он инициализировал name и salary
        super().__init__(name, salary)
        # Добавляем своё новое поле
        self.team_size = team_size

    # Расширяем метод родителя, а не заменяем его
    def get_info(self):
        parent_info = super().get_info()  # Получаем строку от родителя
        return f"{parent_info}, Команда: {self.team_size} чел."


boss = Manager("Иван", 200000, 10)
print(boss.get_info())
# Имя: Иван, Зарплата: 200000, Команда: 10 чел.
```

Как это работает:
super().__init__(name, salary) — вызываем конструктор родителя, чтобы он сделал свою часть работы.
Затем дочерний класс добавляет свои атрибуты (team_size).
В get_info мы получаем готовую строку от родителя и дописываем к ней свою информацию.
