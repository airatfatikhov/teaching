### Организация статических переменных (констант) в Python

В Python нет ключевого слова static или const как в других языках. Однако общепринятой практикой является вынесение неизменяемых значений (констант, конфигураций, настроек) в отдельный модуль. Это улучшает читаемость кода, упрощает поддержку и позволяет избегать "магических чисел" в основной логике.

Структура проекта
Рекомендуемая структура файлов:

```
my_project/
├── config.py      # Файл со статическими переменными
├── main.py        # Основной файл с логикой
└── README.md
```

#### Шаг 1: Создание файла с константами (config.py)

Создайте файл config.py. В нем объявите переменные. По соглашению PEP 8, имена констант пишутся ЗАГЛАВНЫМИ БУКВАМИ с разделением слов нижним подчеркиванием.
```
# config.py

# Строковые константы
APP_NAME = "MySuperApp"
VERSION = "1.0.0"
DEFAULT_LANGUAGE = "ru"

# Числовые константы
MAX_RETRIES = 3
TIMEOUT_SECONDS = 30
PI_VALUE = 3.14159

# Списки и словари (также считаются статическими конфигурациями)
ALLOWED_EXTENSIONS = ["jpg", "png", "gif"]
DATABASE_CONFIG = {
    "host": "localhost",
    "port": 5432,
    "db_name": "my_db"
}
```

#### Шаг 2: Использование в основном файле (main.py)

В основном файле импортируйте нужные переменные из config.py. Есть два основных способа импорта:
##### Способ А: Импорт конкретных переменных (Рекомендуется)
Используйте этот способ, если вам нужно только несколько значений. Это делает код чище и понятнее.

```
# main.py

# Импортируем только то, что нужно
from config import APP_NAME, MAX_RETRIES, TIMEOUT_SECONDS

def start_application():
    print(f"Запуск приложения: {APP_NAME}")
    
    for attempt in range(1, MAX_RETRIES + 1):
        print(f"Попытка подключения {attempt}... Таймаут: {TIMEOUT_SECONDS} сек.")
        # Здесь была бы логика подключения
        break

if __name__ == "__main__":
    start_application()
```

##### Способ Б: Импорт всего модуля
Используйте этот способ, если вы обращаетесь к множеству констант или хотите явно указать их происхождение в коде.

```
# main.py

import config

def show_info():
    print(f"Приложение: {config.APP_NAME}")
    print(f"Версия: {config.VERSION}")
    print(f"Разрешенные форматы: {', '.join(config.ALLOWED_EXTENSIONS)}")

if __name__ == "__main__":
    show_info()
```

#### Запуск примера
Чтобы проверить работу, выполните в терминале:

```
python main.py
```
