# 📦 Переменные

В Python переменная — это не «коробка», в которой лежат данные (как в C++ или Java), а **ярлык (ссылка)** на объект в памяти.

## Базовые принципы и именование

### Правила именования (Идентификаторы)
1. Могут содержать буквы, цифры и символ подчеркивания `_`.
2. **Не могут** начинаться с цифры.
3. **Не могут** совпадать с зарезервированными ключевыми словами (`if`, `for`, `class`, `def` и т.д.).
4. Регистр имеет значение (`Variable` и `variable` — разные переменные).

### Стиль именования (PEP 8)
* **Переменные и функции:** `snake_case` (например, `user_name`, `calculate_total`).
* **Константы:** `UPPER_SNAKE_CASE` (например, `MAX_CONNECTIONS = 100`).
* **Классы:** `CamelCase` (например, `UserProfile`).

```python
# ✅ Правильно
my_variable = 10
_user_private = "secret"
MAX_SIZE = 500

# ❌ Неправильно
# 1variable = 10  (начинается с цифры)
# my-var = 10     (используется дефис)
# class = 10      (зарезервированное слово)
```

### Типы данных
Python — язык с динамической типизацией. Тип переменной определяется в момент присваивания значения и может меняться.
Базовые (скалярные) типы

```
integer_num = 42          # int (целое число). В Python нет ограничения по размеру!
float_num = 3.14159       # float (число с плавающей точкой)
string_text = "Hello"     # str (строка)
boolean_val = True        # bool (логический тип: True или False)
none_val = None           # NoneType (отсутствие значения)
```

#### Коллекции (Составные типы)
```
# list (список) - изменяемый, упорядоченный, допускает дубликаты
my_list = [1, 2, 3, "apple"]

# tuple (кортеж) - неизменяемый, упорядоченный
my_tuple = (1, 2, 3)

# dict (словарь) - изменяемый, хранит пары "ключ-значение"
my_dict = {"name": "Alice", "age": 25}

# set (множество) - изменяемый, неупорядоченный, только уникальные элементы
my_set = {1, 2, 3, 3, 4} # Результат: {1, 2, 3, 4}
```

### Приведение типов
Явное преобразование одного типа в другой с помощью встроенных функций:
```
x = "10"
y = int(x)      # Преобразование строки в int -> 10
z = float(x)    # Преобразование строки в float -> 10.0
w = str(10)     # Преобразование int в строку -> "10"
b = bool(0)     # Преобразование в bool -> False (0, "", [], None дают False)
```

### Изменяемые и неизменяемые типы
Это критически важное разделение в Python!
* Неизменяемые (Immutable): int, float, str, bool, tuple, frozenset. При изменении создается новый объект.
* Изменяемые (Mutable): list, dict, set. Можно менять содержимое, не меняя сам объект (его id).

```
# Пример неизменяемости строк
text = "hello"
# text[0] = "H"  # ❌ Ошибка! TypeError

# Пример изменяемости списков
my_list = [1, 2, 3]
my_list[0] = 99  # ✅ Работает, my_list теперь [99, 2, 3]
```

### Переменные как ссылки (Память)
Когда вы пишете a = 5, Python создает объект 5 в памяти, а переменная a получает ссылку на него.
```
a = [1, 2, 3]
b = a  # b НЕ копирует список. b теперь ссылается на ТОТ ЖЕ список в памяти.

b.append(4)
print(a)  # [1, 2, 3, 4] - список 'a' тоже изменился!

# Как проверить, что переменные ссылаются на один объект?
print(a is b)  # True (сравнивает ссылки/адреса в памяти)
print(a == b)  # True (сравнивает значения)

# Как сделать настоящюю копию?
import copy
c = copy.deepcopy(a) # Глубокое копирование (для вложенных структур)
d = a.copy()         # Поверхностное копирование (для списков)
```

### Области видимости переменных
Локальная (Local): Внутри функции.
Глобальная (Global): На уровне всего модуля (файла).

```
x = 10  # Глобальная

def my_func():
    y = 5  # Локальная
    print(x)  # ✅ Можем читать глобальную
    # x = 20  # ❌ Ошибка UnboundLocalError, если пытаемся изменить без ключевого слова

my_func()
```

### Ключевые слова global и nonlocal
```
count = 0

def increment():
    global count  # Говорим Python использовать глобальную переменную
    count += 1

# nonlocal используется во вложенных функциях
def outer():
    x = 10
    def inner():
        nonlocal x
        x = 20
    inner()
    print(x)  # 20
```
